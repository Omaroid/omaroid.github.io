# Technology logo sources

The compact technology marks in `public/logos/technology/` are static SVGs selected from [Simple Icons](https://github.com/simple-icons/simple-icons), which publishes its icon artwork under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

Bundled assets: Databricks, Apache Spark, Python, TypeScript, Next.js, PostgreSQL, Redis, React, GitHub, Docker, Terraform, Apache Airflow and Vercel.

These assets are **technology trademarks**, not endorsements or partnership claims. Brand ownership and trademark rules remain with their respective owners. Names are displayed only where the technology appears in the project or experience dataset.

The client marks in `BrandLogo.astro` are **original typographic monograms**, deliberately **not official corporate logos**. Do not replace them with third-party artwork unless redistribution and trademark usage have been reviewed.

All logo assets are served from the same HTTPS origin as the portfolio. No hotlink, font import, tracking pixel, remote runtime request or new npm dependency was added.

Build validation checks SVG presence and rejects scripts, inline SVG event handlers and foreign objects.
